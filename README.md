# Balance — site source

Static site for Balance, the cafe & deli in Riverstown, Glanmire, Cork.
No CMS, no framework, no bundler — a small Python template render is the
only build step.

## Editing content (hours, menu, prices, testimonials)

Everything editable lives in **`content/site.json`**. Open it, change the
text, save. Nothing else needs to change — the site regenerates from this
file.

- `hours` — the three rows shown in the Visit section and used in the
  page's structured data.
- `menu.sections` — one object per tab (Morning Bakes, Traditional
  Breakfast, Balance Eggs, Sandwiches & Salads, Soup, Fresh Salads). Each
  `items` entry is `{ "name", "price", "note"?, "signature"? }`.
  `signature: true` adds the small "House favourite" tag.
- `testimonials` — real Google reviews only. Don't invent quotes.
- `gallery` — references image basenames in `assets/images/` (see below).
- `business` — address, phone, socials, price range, feature tags.

After editing, rebuild locally to check it (see below), or just push —
the GitHub Action rebuilds it on every push to `main`.

## Rebuilding locally

```
pip install -r requirements.txt
python3 scripts/build.py      # writes index.html at the repo root
python3 -m http.server 8000   # then open http://localhost:8000/index.html
```

## Assets

- `assets/images/*-src.webp` — original source photos. Never edit these
  directly; they're the source of truth for the generated sizes.
- `assets/images/<name>-<width>.webp` / `.jpg` — responsive variants
  generated by `scripts/build_images.py`. Re-run that script after
  replacing a `*-src.webp` file:
  ```
  python3 scripts/build_images.py
  ```
- `assets/brand/` — the vectorised logo lockup (`logo.svg`), wordmark-only
  version (`wordmark.svg`), and the standalone heart mark
  (`heart-mark.svg`), traced from the real shopfront signage and door
  decal. `favicon.svg` at the repo root is derived from the same trace.
- `assets/fonts/` — self-hosted, subsetted WOFF2 (Fraunces, Caveat, Space
  Mono).
- `assets/vendor/` — vendored GSAP (core, ScrollTrigger, Draggable) and
  Lenis builds. No CDN dependency, no npm install needed to serve the site.

## Deploy

Pushing to `main` triggers `.github/workflows/deploy.yml`, which runs
`scripts/build.py` and publishes the result to GitHub Pages via Actions.
No manual `gh-pages` branch management needed. If Pages isn't enabled yet
on the repo, turn it on once under **Settings → Pages → Source: GitHub
Actions**.

## Stack

Plain HTML/CSS/JS. Jinja2 templating (`templates/index.html.j2` +
`content/site.json` → `index.html`) is the only build step — no
React/Astro/bundler. Motion: Lenis (smooth scroll) + GSAP (ScrollTrigger,
Draggable), vendored locally, all wrapped in a `prefers-reduced-motion`
kill switch.
