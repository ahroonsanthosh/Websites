# Heloria Labs

WebGL website for Heloria Labs. Vite + TypeScript + Three.js + GSAP + Howler,
with GLSL shader support.

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # typecheck + production build
npm run preview  # serve the production build
```

Project conventions, engineering rules and the permanent quality benchmark are
documented in [CLAUDE.md](./CLAUDE.md).
